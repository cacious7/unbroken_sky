# The Unbroken Sky

An original Zambia inspired fantasy game and complete prose story for Cacious Siamunyanga.

A young courier seeks clean water after a river civilisation falls, and discovers that the woman who raised him rescued him from the hidden system that sustained its prosperity. Restoring that system may cost him his independent life.

**Status:** writing package version 1.1, completed 27 October 2026. Full prose story, complete game adaptation and implementation plan are ready for review. The intended first development session is 28 October 2026. No engine project or playable game has been built by this writing task.

## The three main deliverables

1. [Full story](narrative/FULL_STORY.md) — complete prose, dialogue and ending, written to read or hear aloud; no game directions. This is a compact complete telling, not a full-length novel.
2. [Game script](narrative/FINAL_SCRIPT.md) — scenes, essential dialogue, playable objectives, choices, both endings, epilogue variants and encounter notes.
3. [Implementation plan](development/IMPLEMENTATION_PLAN.md) — first sessions beginning 28 October, full milestones, systems, scope, assets, testing and review gates. Dates are intended work sessions, not automatic appointments.
